# Sample workspace

Opened automatically by the **Run Extension (sample workspace)** launch config.

- `Localizable.xcstrings` — a String Catalog covering every case the grid draws:
  a plural key, a format specifier that has gone missing from its translation,
  `needs_review`, and keys in each extraction state so the "−" button's rules are
  visible.
- `en.lproj` / `fr.lproj` — a legacy `.strings` table.
- `Sources/` — Swift and TypeScript referencing some of the keys, for
  **Find in code** and **Find unused keys**.
